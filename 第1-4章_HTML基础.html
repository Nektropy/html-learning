第 1 章 · 网页是什么？HTML 名字的由来

1.1 一句话理解网页

你看到的每一个网页（包括现在这个页面），本质上是一个普通的文本文件， 里面写着两样东西：内容（有哪些字、哪些图）和标记（哪个字要大、要在哪儿换行）。 浏览器负责把这个文本文件“翻译”成你看到的画面。

写这种文件用的语言，就叫 HTML，全称是 HyperText Markup Language（超文本标记语言）。

Hyper超级的、超过的前缀
Text文本；文字n.
HyperText超文本（能“点一下跳走”的文字）n.
Markup标记（用尖括号告诉浏览器这是什么）n.
Mark标记、做记号v./n.
Language语言n.
browser浏览器n.
display / render显示 / 渲染v.

“超文本”里的“超”（Hyper），意思是：一段文字可以指向另一段文字。 点一下，就跳过去了。这个“点一下跳走”的能力，后来发展成了网页上最重要的东西之一 —— 链接。

小故事 · 互联网最初只有“超文本”三个字

上世纪 60 年代，一个叫 Ted Nelson（泰德·尼尔森）的美国学者，想造一个“全世界所有文献连成一张网”的系统。 他造了两个词：hypertext（超文本）和 hypermedia（超媒体）。 “hyper” 来自希腊语，本意是“在……之上、超越”，就像 geometry（几何）里的 “hyper+ ” 还能拼出 hyperplane（超平面）一样。 他当时根本没想到，几十年后，“超文本”这三个字会让所有人都能点着链接从一个网页跳到另一个网页。

1989 年，在欧洲核子研究中心（CERN）工作的英国人 Tim Berners-Lee（蒂姆·伯纳斯-李）写了一份提案： 把“超文本”和当时刚出现的互联网（internet）结合，让不同的计算机之间能互相链接文档。 这个想法被命名为 World Wide Web（万维网，简称 WWW）。“World”（世界）、“Wide”（广泛的）、“Web”（网）。 为了写这些文档，他造了一门标记语言，就叫 HTML。

顺带一提：他发明这套东西之后，没有申请专利，而是让它免费给全世界用。所以你今天能免费学到它。

1.2 HTML 的样子：尖括号

HTML 只有一件事要做：用尖括号把内容“包起来”，告诉浏览器这是什么。

<h1>我是标题</h1>
<p>我是一个段落。</p>

翻译成中文：

  • <h1> 到 </h1>，意思是：这中间的文字是“一级标题”。h 是 heading（标题）的缩写，1 表示最大。
  • <p> 到 </p>，意思是：这中间的文字是一个“段落”。p 是 paragraph（段落）。
headingh 的来源：标题n.
paragraphp 的来源：段落n.
quoteq 的来源：引用n.
imageimg 的来源：图像（图片）n.
list列表n.
item项目（列表里的一条）n.
un-ordered无序的adj.
ordered有序的adj.
title标题（网页标签栏上那个字）n.
为什么代码里都是英文？ 因为 HTML 是英语国家的第一门网页语言，这些缩写（h1、p、img、li……）都是英文单词的首字母。 不擅长记忆的话，你的策略是：不用背，看着表格、看着代码，混个眼熟。 以后每次见到 <li>，就顺带念一遍 “list item（列表项）”，见两次就记住了。

1.3 三层分工：HTML、CSS、JavaScript

给游戏角色设计的三层：

语言全称中文管什么打个比方
HTMLHyperText Markup Language超文本标记语言页面上有什么骨架
CSSCascading Style Sheets层叠样式表长什么样皮肤 / 衣服
JavaScriptJavaScriptJavaScript 脚本动起来、会思考肌肉和大脑

做一个贪吃蛇，这三样都要一点：HTML 是页面上那块画布，CSS 是配色和边框， JavaScript 是蛇怎么走、吃什么、撞墙怎么办。

第 2 章 · HTML 骨架：把文件写对

2.1 一个网页的最小“骨架”

每个 HTML 文件，都应该有这个骨架：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>你好，世界</h1>
  <p>这是我的第一个网页。</p>
</body>
</html>

逐行翻译：

这一行意思是
<!DOCTYPE html>告诉浏览器：这是 HTML 文件。DOCTYPE 是 document type（文档类型）的缩写。
<html lang="zh-CN">整个文件的最外层。lang 是 language，zh-CN 表示简体中文（中国）。
<head> … </head>“头部”：给浏览器看的信息，不会直接显示在页面上。
<meta charset="UTF-8">文件的编码方式。charset 是 character set（字符集），UTF-8 是国际通用的那种。
<title>…</title>浏览器标签栏上显示的文字。
<body> … </body>“身体”：所有用户能看到的内容都写在这里。
document文档n.
type类型n.
declare声明v.
head头部n.
body身体（正文）n.
meta“关于数据的数据”，这里的设定型信息adj.
character字符n.
set集合n.
charset字符集（character + set）n.
UTF-8Unicode Transformation Format - 8 bit（万国码，8 位格式）n.
lang语言（language 的缩写）n.
最常见的第一个坑 · 中文变成乱码 如果 <meta charset="UTF-8"> 这一行漏了，或者写错了，中文可能显示成“锟斤拷”（一段乱码）。 解决方法：一旦乱码，第一件事就是检查这一行。

2.2 标签的两种写法

HTML 的标签，就是尖括号里面的英文单词。大多数成对出现，但有几个是“单身”的：

类型写法例子
成对标签<开始> 内容 </结束><p>你好</p>
单标签（空标签）<标签>，没有结束的部分<img>（图片）、<br>（换行）、<hr>（分隔线）
怎么一眼区分？ 找那一根竖杠：</p> 里多了一个 /（斜杠，读作 slash），意思就是“结束”。 没有斜杠，就是“开始”。

2.3 文件的保存：.html 后缀

  1. 用记事本（Notepad）或者 VS Code 打开一个新文件。
  2. 把上面的骨架代码抄（或复制）进去。
  3. 保存时，文件名写成 hello.html，保存类型选“所有文件”，编码选 UTF-8。
  4. 在文件夹里双击这个文件，浏览器就会打开它。
常见坑 · 后缀变成了 .html.txt 记事本保存时，如果“保存类型”没改，可能会自动加上 .txt，文件变成 hello.html.txt，浏览器就不会把它当网页打开。 在 Windows 里怎么看真实后缀？资源管理器 → 查看 → 勾选“文件扩展名”。 推荐工具：VS Code（免费的代码编辑器，能帮你检查错误）。
先试试看 打开 样板_你好世界.html（和你学的一模一样）， 再用记事本打开它，把 你好，世界 改成你自己的话，保存，刷新浏览器，看效果。

2.4 缩进：为什么代码要“往里缩”

浏览器不在乎代码前面有几个空格。但人很在乎。 把里面的标签往右缩进，就能一眼看出“谁包在谁里面”： 

<body>
  <h1>标题</h1>
  <p>段落</p>
</body>

上面这段里，<h1> 和 <p> 缩进了 2 格，表示它们是 <body> 的“孩子”。 在 VS Code 里按 Shift + Alt + F 可以自动整理缩进，按 Ctrl + S 保存。

第 3 章 · 加内容：标题、段落、列表、图片

3.1 标题 h1 到 h6

标题一共有 6 级，h1 最大，h6 最小：

<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h6>六级标题（最小的标题）</h6>

浏览器会自动把 h1 显示得很大、h6 显示得很小，你什么都不用做。一个页面建议只用一个 h1。

3.2 段落与换行

段落 p 是最常用的标签。在 HTML 里，代码里的换行和多余空格，浏览器会当成一个空格：

<p>
  这一行的
  文字，
  写的时候换了很多行，
</p>

显示出来是连成一句话的。如果你真想换行，要用 <br>（break 的缩写，断开）：

<p>第一行<br>第二行</p>
breakbr 的来源：打断、换行v.
horizontalhr 里的 h：水平的adj.
rulehr 里的 r：线、横线n.
strong加粗：强壮、强烈adj.
emphasisem 全部：重点、强调n.
boldb 的来源：粗体的adj.
italici 的来源：斜体的adj.

3.3 加粗和斜体

<p>
  这句话里有<strong>重点</strong>，
  也有<em>强调</em>。
</p>

<strong>（strong，强）会让字变粗；<em>（emphasis，强调）会让字变斜。 老代码里你可能看到 <b>（bold，粗体）和 <i>（italic，斜体），它们效果差不多， 但 strong 和 em 更“有含义”，现在更推荐用 strong 和 em。

小故事 · 为什么“加粗”和“强调”要分成两个标签？

早期网页里，<b> 就是“变粗”，<i> 就是“变斜”，说的全是长相。 后来有人发现：如果一个人用朗读软件（读屏软件）听网页，它读不出“粗”和“斜”， 但能读出“这里有重点”。于是 HTML 加了一对更“讲道理”的标签：strong（内容重要）和 em（语气强调）。

这背后是一个道理：HTML 管“是什么”，CSS 管“长什么样”。到了第 5 章你就会发现，CSS 也能让 strong 不变粗 —— 长相的事，交给 CSS 就好。

3.4 列表：ul / ol / li

列表由“列表容器”和“列表项”两层组成。列表项都用 <li>（list item，列表项）：

<ul>
  <li>苹果</li>
  <li>香蕉</li>
</ul>

<ol>
  <li>先洗手</li>
  <li>再吃饭</li>
</ol>
标签英文全称中文效果
<ul>unordered list无序列表前面是圆点 •
<ol>ordered list有序列表前面是数字 1. 2. 3.
<li>list item列表项列表里的一条
order顺序、次序n./v.
ordered有顺序的adj.
unordered没有顺序的adj.
item项目、条目n.
常见坑 · li 写出来了，但没有外面的容器 <li> 必须写在 <ul> 或 <ol> 里面。 如果你的圆点没显示出来，先检查是不是忘了给 li 套一层 ul。

3.5 图片 img

图片是少数几个“单身标签”之一，它用属性来说明自己是谁：

<img src="cat.jpg" alt="一只猫">
属性英文全称中文作用
srcsource来源（地址）图片文件在哪里
altalternative替代文字图片加载不出来时显示的说明；盲人读屏软件也会读它
sourcesrc 的来源：来源n.
alternativealt 的来源：替代的adj.
width宽度n.
height高度n.
filename文件名n.
folder / directory文件夹 / 目录n.
path路径n.

如果图片和网页放在同一个文件夹，src 里只写文件名就行。如果图片在下一层的 img 文件夹里：

<img src="img/cat.jpg" alt="一只猫">

img/cat.jpg 表示“进到 img 文件夹，找 cat.jpg”。这个斜杠是文件夹的分隔，跟标签结束的那个斜杠不是一回事。

常见坑 · 路径和文件名大小写 Cat.jpg 和 cat.jpg 在 Windows 里被当成同一个文件，但传到服务器上就成了两个不同的文件。 养成习惯：文件名全部用小写英文字母加数字，不要用中文、空格。

3.6 链接 a

“超文本”的那个“超”字，在代码里就是链接：

<a href="https://developer.mozilla.org">MDN 开发者文档</a>
标签 / 属性来源中文
<a>anchor锚（把它“锚”到一个网址上）
hrefhypertext reference超文本引用

MDN（Mozilla Developer Network）是最权威的 HTML 学习网站之一。 以后遇到不懂的标签，搜 “MDN 标签名”，几乎都能查到。比如搜 “MDN ul”。

3.7 把它们拼起来

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的介绍页</title>
</head>
<body>
  <h1>我是杨过</h1>
  <p>今年 <strong>十八</strong> 岁，正在学做网页。</p>

  <h2>我喜欢的三样东西</h2>
  <ul>
    <li>写代码</li>
    <li>玩贪吃蛇</li>
    <li>看历史故事</li>
  </ul>

  <h2>我学习网页的顺序</h2>
  <ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ol>

  <p>
    我最常查的网站是
    <a href="https://developer.mozilla.org">MDN</a>。
  </p>
</body>
</html>
看一下效果 打开 样板_我的介绍页.html， 这就是上面这段代码在浏览器里真实的样子。

第 4 章 · 小练习：做一个属于你自己的介绍页

把下面的代码抄下来，把带 —— 的地方改成你自己的内容。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>—— 你的名字 —— 的介绍页</title>
</head>
<body>
  <h1>—— 你的名字 ——</h1>

  <h2>关于我</h2>
  <p>
    —— 用一两句话介绍自己，比如：“我是一个正在学 HTML 的学生。” ——
  </p>

  <h2>我的目标</h2>
  <ul>
    <li>学会写网页</li>
    <li>—— 你的一条目标 ——</li>
    <li>—— 你的另一条目标 ——</li>
  </ul>

  <h2>我的时间表</h2>
  <ol>
    <li>周一：—— 做什么 ——</li>
    <li>周二：—— 做什么 ——</li>
    <li>周三：—— 做什么 ——</li>
  </ol>
</body>
</html>

改完以后，保存成 about.html，双击打开。

小检查清单

  • 标签是不是都有结束？（除了 img、br、hr、meta 这类单身标签）
  • 每对标签里，是不是都用了同一层的尖括号？
  • 开头有 <!DOCTYPE html> 吗？
  • 有 <meta charset="UTF-8"> 吗？
  • 标题是不是用 h1 到 h6，而不是让文字自己变大？
小故事 · 这段骨架为什么叫“Hello World”

几乎所有编程教程的第一课，都是让程序打印一句 “Hello, World!”（你好，世界！）。 这个传统来自 1972 年贝尔实验室的研究员 Brian Kernighan（布莱恩·柯林汉）。 他在 A Tutorial Introduction to the Language B 里，用了一句 “hello, world!”， 后来又写进了最著名的 C 语言教程《The C Programming Language》（C 语言程序设计）的第一页。 从那以后，几千种编程语言、几十种教程，都从这句话开始。

所以不用担心自己的第一个页面是不是太简单 —— 全世界所有的程序员，都是在这句话里起步的。

第 5 章 · CSS 是什么：一条规则拆成两半

CSS 全称 Cascading Style Sheets，翻译成中文是“层叠样式表”。

  • Style（样式）= 字号、颜色、位置……这些“长相”。
  • Sheet（表）= 它写成一张“风格清单”，不是散落在每个标签里的。
  • Cascading（层叠）= 同一条规则如果被写好几次，后写的、写得更具体的会“盖住”前面的（像传了一层又一层）。

5.1 把 CSS 放到 HTML 里

最省事的方式：在 <head> 里写一个 <style>（样式）标签，把 CSS 写进去。

<head>
  <meta charset="UTF-8">
  <title>测试</title>
  <style>
    /* 这里是 CSS 注释，浏览器会忽略它 */
    h1 {
      color: red;
      font-size: 40px;
    }
  </style>
</head>
两种注释别搞混
HTML 的注释：<!-- 这样写 -->
CSS 的注释：/* 这样写 */
它们只在各自的“地盘”里有效。写注释是好习惯，尤其是你以后回头看自己的代码时。

5.2 一条 CSS 规则的形状

h1 {
  color: red;
  font-size: 40px;
}
选择器 {           ← 选谁（selector）
  属性: 值;        ← 改什么（property: value），每句用分号结尾
}
部分英文中文这段代码里是
h1selector选择器所有的一级标题
colorproperty属性颜色
redvalue值红色
color: red;declaration声明一句完整的设定
三个最常见的 CSS 语法错误
  • 忘了写分号 ;
  • 属性名和值之间用的是等号 =，其实应该是冒号 :
  • 花括号成对写反了：{ 对应的是右花括号 }，不是圆括号

5.3 颜色怎么来的：红绿蓝和 hex

电脑屏幕由三种小灯组成：红（Red）、绿（Green）、蓝（Blue），英文缩写 RGB，每种灯亮度从 0 到 255。

color: rgb(255, 0, 0);      /* 255 红、0 绿、0 蓝 → 纯红 */
color: #ff0000;             /* 上面那一句的“十六进制”写法，也是纯红 */
color: #ff6b6b;             /* 亮一点的珊瑚红，贪吃蛇的食物常用 */
color: #1f2328;             /* 接近黑色的深灰，比纯黑柔和 */

#ff0000 里的 # 读作 “hash”（井号），后面 6 位十六进制数，两两一组： ff 是红色亮度、00 绿色、00 蓝色。ff 是最大的（等于 255），00 最小。

小故事 · 为什么是 0 到 255，为什么是 ff

计算机最小只认“开”和“关”两种状态。8 个开关排成一排，能表示 0 到 255 共 256 种亮度（因为 2 的 8 次方 = 256）。 用十六进制写，最大的 255 正好是 ff，只要两个字符就够。所以红绿蓝各占 2 位，加起来 6 位。

每多一位，能表示的颜色就翻 16 倍。6 位数不过 1677 万种颜色，就装下了人眼能分辨的大多数颜色。

第 6 章 · 选择器：class 和 id 是什么

如果选择器只能写 h1、p，那所有 h1 都会变成同一个样子。想让某些元素单独变样，就要先给它们起名字。

6.2 class 和 id 有什么区别？

classid
一个页面里能用几次随便用多少次只能有 1 次（不能重复）
能不能拆开写能：class="card big"不能
CSS 里怎么写.card（点）#score（井号）
适合用来确定外观（一堆东西长得一样）唯一的东西：游戏画面、分数牌、按钮

记住一个口诀：class 加点，id 加井号。 再看看代码里的 <div id="game">、<canvas id="board"> —— 这些在贪吃蛇里就是这么用的。

小故事 · id 的祖先：SGML 里的“唯一编号”

HTML 里的 id，最早来自一种更古老、更庞大的标记语言 SGML（Standard Generalized Markup Language，标准通用标记语言）。 HTML 其实就是从 SGML 里“瘦身”出来的一种应用。

SGML 规定文档的每一样东西都可以有一个 ID（Identifier），像图书馆里每本书的编号，独一无二。 当年发明它的人是为了“检索方便”，结果今天你在浏览器控制台里用 #board 就能精确找到那块画布 —— 完全是同一个思路。

6.3 后代选择器：选“谁里面的谁”

#game h2 {
  color: white;
}

意思是：“id 为 game 的元素里，所有的 h2”。中间用空格隔开，读作“里面的”。这个能力在贪吃蛇的打开页、结束页会用上。

6.4 行内样式（不推荐，但要知道）

<p style="color: red;">这一行是红的</p>

可以直接把 CSS 塞进标签里，叫 inline style（行内样式）。 它的问题在于：改的时候要一个个去找，而且优先级别最高，覆盖起来很麻烦。 知道就行，平时尽量用 class 和 id。

第 7 章 · 盒子模型：边距、内边距、边框

网页上每一样东西，浏览器都把它当成一个长方形的盒子（box）。这个盒子由里到外分四层：

  1. content（内容）：文字、图片本身。
  2. padding（内边距）：内容和边框之间的“填充”。
  3. border（边框）：盒子的边线。
  4. margin（外边距）：盒子外面，和别的盒子之间的距离。

看一眼这个盒子：橙色的芯是内容，浅橙是 padding，红色粗线是 border，盒子外面那圈空白是 margin

content
content内容n.
padding内边距（往里垫）n.
border边框n.
margin外边距（外面的空地）n.
box盒子n.
outer / inner外面的 / 里面的adj.
spacing间距n.
怎么记 padding 和 margin？ padding 和 border 都是 p、r 开头的？用“边界”想：border 是墙；padding 是墙里面的垫子（在内容身边）；margin 是墙外面的院子（在别人身边）。

7.1 简写：一个属性管四边

padding: 10px;                  /* 上下左右都是 10px */
padding: 10px 20px;             /* 上下 10px，左右 20px */
padding: 10px 20px 30px 40px;   /* 上 右 下 左（顺时针） */

margin: 0 auto;                 /* 上下 0，左右自动 —— 水平居中 */

px 是 pixel（像素）的缩写，屏幕上最小的一个点。 如果顺口，可以读成 “10 像素”。

pixel像素（px）n.
em / rem相对于字体大小的单位n.
percent百分比（%）n.
auto自动adj.
clockwise顺时针（简写的顺序）adv.

7.2 宽度和高度

#board {
  width: 480px;
  height: 480px;
}

width（宽度）和 height（高度）决定盒子的尺寸。 到了贪吃蛇里，画布就是这个尺寸：24 格 × 20 像素 = 480 像素。

7.3 box-sizing：一个让所有新手头疼的坑

默认情况下，width: 480px 只算内容，padding 和 border 会额外加上去。 所以一个“480 宽的盒子”加上 padding 以后，实际会超过屏幕。

加一句：

* {
  box-sizing: border-box;
}

意思是：让 width 把 padding 和 border 也算进去。 * 是“全部元素”的通配符；border-box 字面意思是“边框盒子”，即“宽度包含到边框为止”。 几乎所有现代网站第一句 CSS 都是它。

小故事 · 为什么突然给网页加了第五种盒子

2012 年，当时的 CSS 标准里，盒子尺寸的计算方式只有一种：width 只管内容。 这让所有写网页的人都得天天算“边框要塞到哪里”。 微软在 IE 浏览器里曾经用另一种算法（宽度包含边框），结果反而让页面更好算，但大家为了兼容不得不给两种浏览器写两套代码。

于是 W3C 后来正式加入了 box-sizing 属性。一句 box-sizing: border-box， 让盒子回到 IE 时代那种“所见即所得”的尺寸 —— 这就是今天几乎所有网站都会写第一句 * { box-sizing: border-box; } 的原因。

8.2 居中的三件事

“居中”是新手最常卡住的地方。记住：文字居中和盒子居中是两回事。

  • 文字居中：text-align: center;
  • 一个盒子水平居中：margin: 0 auto;（有宽度才有效）
  • 盒子里的东西整体居中：用第 9 章的 flex：display: flex; justify-content: center; align-items: center;

8.3 圆角、阴影、透明度

  box-shadow: 0 8px 30px rgba(0, 0, 0, .35);   /* 阴影 */
  opacity: .8;                        /* 透明度：0 是透明，1 是不透明 */
  cursor: pointer;                    /* 鼠标移上来变成小手 */
}

9.3 grid：把区域划成格子

.board {
  display: grid;
  grid-template-columns: repeat(6, 1fr);   /* 6 列，每列一样宽 */

}

grid-template-columns 意思是“网格模板的列”；repeat(6, 1fr) 意思是“重复 6 次，每次占 1 份”。 fr 是 fraction（分数、份额）的缩写。

小故事 · CSS 一开始只是个“排版建议”

1994 年，网页刚兴起几年，HTML 里其实是可以直接写“文字颜色”和“字体”的，比如 <font color="red">。 但这样写的问题很快出现：一页 500 行，想改个颜色，得一行一行改。

挪威的一个工程师 Håkon Wium Lie（哈肯·维姆·莱）提出了一个想法：把“内容”和“长相”分开， 长相单独写在一个文件里。这就是 CSS 的起点。后来他和 Tim Berners-Lee 一起在 CERN 工作，推动它成了正式标准。

“Cascading”（层叠）这个词，就来自他的一个原则：多个样式表可以并存，浏览器按优先级一层一层盖上去。 所以，你写下的每一条 CSS，都是在这条很长的“瀑布”上盖的一层。

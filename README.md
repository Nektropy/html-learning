# HTML 入门到贪吃蛇

一套写给“不擅长记忆”的中文 HTML 教程：从网页是什么开始，一路做到一个能玩的贪吃蛇。

- 每一行代码都配**完整的英文单词和翻译**（`li` = list item、`hr` = horizontal rule、`charSet` = character set……）
- 每章末尾有**单词表**，首页有**速查卡**，随时回查，不用背
- 每个关键概念都配了**小故事**：HTML 的由来、CSS 为什么叫 “Cascading”、颜色为什么是 0–255、贪吃蛇 1976 年叫 Blockade……

## 两个小坑，教程里专门讲了

1. **快速连按方向键会“自杀”**：蛇向右走时，同一秒内先按 ↑ 再按 ←，方向被立刻覆盖，下一步就撞进自己的身体。解决办法是加 `nextDirection` 缓冲，走一步之前才换方向（第 11 步）。
2. **按方向键整个网页在滚**：需要 `event.preventDefault()` 把浏览器的默认行为拦掉。

## 本地运行

直接双击 `index.html` 就能看，不需要安装任何依赖。想用本地服务器的话：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000/>。

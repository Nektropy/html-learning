常见错误对照表

下面这些都是新手最常碰到的。报错了先来这找一找，80% 的问题都能对号入座。

你看到的现象最可能的原因怎么办
中文变成一串乱码没写 <meta charset="UTF-8">补上这一行，放在 <head> 里
双击文件，用记事本打开了后缀不是 .html检查是不是变成了 .txt；右键 → 打开方式 → 选浏览器
页面一片空白标签没闭合 / 内容写到了 </body> 外面检查每一个 <xxx> 是不是都有 </xxx>
图片显示一个破图标src 的路径或文件名写错了图片和网页放在同一个文件夹，文件名区分大小写
圆点或数字列表没出来li 外面没有 ul 或 ol把 li 放进列表容器里
CSS 完全没生效花括号写成了圆括号、漏了分号检查 { } 和 ;；选择器里的点是英文句号 .
改了 CSS 但没变化没保存，或者没有刷新Ctrl + S 保存，回到浏览器按 F5 刷新
控制台报 “null”getElementById 里的 id 和标签上的 id 对不上两边名字必须一模一样（大小写也算）
控制台报 “is not a function”拼写错了：中文逗号、中文引号、多了个空格把输入法切到英文；检查 " " 和 ' ' 是不是真的英文
按方向键整个页面在滚没有 event.preventDefault()第 10 章有讲：在 keydown 里先把它拦下来
蛇撞进自己身体还以为没按错方向改得太早（第 11 章那个坑）用 nextDirection 缓冲：走一步之前才换方向
画布是空的getContext 里写成了 "2D"，返回 null必须是 "2d"，小写
最重要的一个习惯：按 F12 在浏览器里按 F12 打开开发者工具，点 “Console”（控制台）标签页。 代码一报错，那里就会出现 红色的一行字，还会告诉你“在第几行”。 看不懂没关系，把那一行红色字抄下来，回 上面的对照表 里找。

学习路线建议

  1. 先玩一遍：打开 贪吃蛇_最终版.html，你知道目标是什么，才学得进去。
  2. 第 1 — 4 章：跟着写一个“我的介绍页”。不追求好看，能打开就行。
  3. 第 5 — 9 章：改 样板_卡片.html，每改一个属性就刷新看一次。
  4. 第 10 章：从 step1 开始，每一步都自己抄一遍，跑通了再抄下一个。
  5. 第 11 章：理解“快速连按会自杀”那个坑，你会比很多教程都懂贪吃蛇。
  6. 自己改：改颜色、改速度、加暂停、加最高分——贪吃蛇最终版里这四样都已经有了，读得懂你就毕业了。
不要做的一件事：一开始就对着完整代码逐行“背” 你不需要记住任何代码。你需要的只是：知道每一段在干什么。 等到真要写的时候，再回来查速查卡，抄一抄、改一改，几次就熟了。
